# Say It, Log It

A voice calorie tracker. Tap the mic, say what you ate ("two eggs, toast with butter and a latte for breakfast"), check the estimate and add it to your day.

- Voice input uses the browser's speech recognition (Chrome, Edge, Safari).
- Calories and macros come from a built-in list of common foods; you can edit any number before adding it.
- Your log, daily goal and 7-day history are saved in your browser on that device.

It's a single static page (`index.html`), served with GitHub Pages. Open the site on your phone and use "Add to Home Screen" to install it like an app.
